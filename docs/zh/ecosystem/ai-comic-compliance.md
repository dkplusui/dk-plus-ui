## 为什么放在前面

内容风险有两个特点：一是**发现晚**——成片做完才发现素材不能用、题材违规，返工成本最高；二是**判据会变**——各平台与监管口径更新很快，今天能发的题材下周可能受限。

所以合规不是发布前的最后一步，而是选题时的一次筛除。下面只写可以自己核验、有明确动作的部分，不引用来源不清的政策解读和补贴汇总。

## 授权链路

### 素材侧

| 素材类型   | 需要确认的授权范围                                   |
| ---------- | ---------------------------------------------------- |
| 原作与改编 | 改编权、传播权、信息网络传播权，是否可商用与可再授权 |
| 剧本与角色 | 是否为原创或已获授权，人物与名称是否与在世作品撞车   |
| 音乐与音效 | 商用许可、是否可跨平台分发、署名要求                 |
| 字体       | 商用许可与嵌入许可，字幕字体最容易漏                 |
| 图片与肖像 | 出处、模特肖像授权、是否可用于商业推广               |
| 生成模型   | 服务条款是否允许商用与对外发布                       |

### 小说改编授权

需要从零做起时，通常按这个顺序推进：

- **如何选书**：平台热度、改编难度、版权状态。
- **如何获取授权**：个人达人申请、版权合作、平台官方入口。
- **版权申请流程**：走平台提供的版权个人达人申请通道，按要求提交样片和资料。
- **官方入口**：各小说分发平台的达人中心与版权合作页面，以平台当期指引为准。

> 授权拿不到就不要开工。改编一部无授权的作品，收益远低于换一本能授权的书。

## AI 生成内容标识

- 发布时按平台要求保留 AI 生成标识，不要去除水印或伪装为实拍。
- 记录生成工具与生成时间，便于事后核查。
- 平台规则对 AI 标识的要求可能不同，多平台分发时按最严格的一档执行。

## 人工审核不可省

AI 可以提高单个环节的效率，但替代不了对故事、审美和成片质量的判断。发布前至少完成三轮检查：

1. **事实与逻辑**：设定、时间线、人物行为是否自洽。
2. **版权与合规**：对照上面的红线清单逐项过。
3. **一致性与错字**：角色一致性、字幕错别字、画面文字。

## 政策方向怎么看

生成式人工智能与文化、视听、数字内容的融合是明确的发展方向。对创作者真正有影响的，不是某一句「行业风口」，而是以下四类要求正在逐步变得具体：

- **生成内容治理**：对深度合成、生成式内容标识、虚假信息和不当内容进行审核。
- **数据与模型规范**：关注训练数据、视听素材采集与标注、模型评测和安全边界。
- **知识产权保护**：剧本、原著、角色、音乐、字体、肖像和生成结果都需要明确授权范围。
- **视听行业标准化**：虚拟数字人、生成式视听、内容生产与传播越来越强调流程留痕和责任主体。

政策会更新。立项前应以国务院、国家广播电视总局、国家互联网信息办公室和发布平台的最新文件为准，不把培训机构的二手解读当成合规结论。

## 地方扶持怎么核验

地方补贴的名称、申报时间和适用主体变化很快。相比照抄一张过期的汇总表，更可靠的做法是按下面的清单逐项核验：

| 核验项     | 需要确认的内容                                             |
| ---------- | ---------------------------------------------------------- |
| 申报主体   | 个人、工作室、企业，是否要求本地注册或实际经营             |
| 支持方向   | 网络视听、数字文化、动漫、短剧、AIGC、软件或文创项目       |
| 支持方式   | 项目补贴、房租补贴、人才奖励、贷款贴息、赛事奖金或流量资源 |
| 申报条件   | 营收、纳税、软著、作品备案、播放数据、获奖情况和团队规模   |
| 材料与周期 | 申报指南、预算、合同、发票、验收材料和截止日期             |
| 兑现风险   | 是否先投入后验收，是否存在名额、评分或拨付时间不确定性     |

查找时优先访问所在地政府、文旅、广电、经信或宣传部门官网，并搜索「数字文化」「网络视听」「动漫」「微短剧」「人工智能」等关键词。**补贴只能作为额外收益，不能作为项目成立的唯一前提**——先按上一条核验清单逐项确认，再决定要不要投入制作成本。
