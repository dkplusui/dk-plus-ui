## 环节一选题与定位

先写清楚目标受众、内容类型和核心冲突。一个选题最好能用一句话说明「谁遇到了什么问题，以及为什么值得继续看」。

不要用「讲一个关于复仇的故事」这种描述，那是题材不是定位。定位句要包含人群、处境和继续看的理由。

- 产出物：一句定位陈述 + 目标受众画像。
- 检查点：说不清这句话，说明选题还没收敛，先别开做。
- 常见问题：选题看起来很大但没有具体的人，这类选题做出来留存一定差。

## 环节二剧本与节奏

把故事拆成开场、推进、转折和收束。每个场景只承担一个主要信息点，并为对白、旁白和画面分别标注用途，避免所有信息都依赖字幕表达。

节奏划分、分场结构和分镜输出格式属于最容易直接复用的部分，见<a href="/zh/ecosystem/ai-comic-prompts#剧本与文案">提示词与素材规范</a>。

- 产出物：分场剧本 + 每场的信息点标注。
- 检查点：任意一场删掉后故事是否仍成立，成立说明该场冗余。
- 常见问题：一集塞三件事，观众一件也没记住。

## 环节三角色与视觉规范

建立角色卡，记录发型、服装、体型、表情、性格和常用动作；同时确定画幅、色彩、线条与光影风格。先完成少量测试镜头，再扩展整集，可以显著减少返工。

角色卡字段、三视图规格和画风分类见<a href="/zh/ecosystem/ai-comic-prompts#角色与画风">提示词与素材规范</a>。

- 产出物：角色卡 + 视觉规范页。
- 检查点：用规范跑通 3 个测试镜头再量产。
- 常见问题：只写了「女主，20 岁」，没有服装、发型和体型，跨集必然漂移。

## 环节四分镜与画面

为每个镜头写明景别、机位、人物动作、背景和持续时间。生成画面后优先检查角色一致性、手部细节、文字错误、空间关系和镜头衔接。

先做纯场景镜头时要加强约束，避免人物串进背景，规则见<a href="/zh/ecosystem/ai-comic-prompts#纯场景提示词">纯场景提示词</a>。

- 产出物：分镜表 + 画面素材。
- 检查点：角色一致性由固定人选抽查，不靠生成方自评。
- 常见问题：画面里出现文字（招牌、屏幕），AI 生成的中文字几乎都是错的，能删就删。

## 环节五配音与声音

根据角色性格统一音色和语速，为重点对白预留停顿。背景音乐负责情绪，环境音负责空间感，音效负责动作反馈；三者都不应压过人声。

音色分类维度和跨集一致性控制见<a href="/zh/ecosystem/ai-comic-prompts#声音规范">提示词与素材规范</a>。

- 产出物：配音轨 + 三层声音混音。
- 检查点：戴耳机听，人声是否始终清晰突出。
- 常见问题：整集一个语速、一条平读到底，情绪没有起伏。

## 环节六剪辑与发布

先完成粗剪，再添加镜头运动、转场、字幕和声音细节。发布前检查开场吸引力、信息节奏、字幕可读性、版权风险和不同屏幕上的观看效果。

- 产出物：成片 + 发布版本。
- 检查点：手机小屏、外放、竖屏三条件下各看一遍。
- 常见问题：在电脑大屏上剪完就发，竖屏字幕被裁掉一半。
