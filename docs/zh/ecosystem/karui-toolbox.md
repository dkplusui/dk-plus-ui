## 安装使用

1. 前往 [Karui 工具箱下载页](https://karuibi.docs.dk-plus.com/toolknit-desktop.html) 查看当前版本和完整模块截图。
2. 下载 Windows 安装包并在本地运行。
3. 从左侧分类进入所需模块；AI 功能可先在密钥页完成配置。

> 工具箱正在持续更新，最新版本与下载入口以官方文档页为准。
