## 怎么用这份规范

提示词分两类：**可复用的模板**（结构稳定，照抄即可）和**需要实测的参数**（时长、字数、分类粒度，各模型表现不同）。标注方式：

<div class="ecosystem-feature-grid">
  <div class="ecosystem-feature-card"><strong>共识度高</strong><p>被大量实践独立采用的同一做法，可信度最高，直接用。</p></div>
  <div class="ecosystem-feature-card"><strong>存在分歧</strong><p>不同做法给出不同参数，需要按自己的模型实测后确定。</p></div>
  <div class="ecosystem-feature-card"><strong>已知坑点</strong><p>多人踩过的坑，提前规避比事后返工划算。</p></div>
</div>

> 提示词效果与具体模型强相关。模板是起点不是终点：用之前先用自己的账号跑一集，把不生效的约束删掉、有效的约束补进去，再把踩过的坑写回本页。整季只调模板的参数位，结构不要每集改。

## 剧本与文案

### 小说改文

把小说片段改成短视频文案时，核心要求高度一致：主题不改、开头反转、删铺垫提高冲突密度、结尾留钩、文字能直接转成分镜、正向价值收束。下面这套模板把六条要求都写成了硬约束。

```text
你是短剧改编编剧。把我提供的小说片段改写为竖屏漫画式短剧文案。

【硬性要求】
1. 保持原文主题与主线不变，不新增与主线无关的人物和支线。
2. 开头 3 秒必须出现钩子：用反常识、反逻辑的对比或反差制造悬念，禁止用背景铺垫开场。
3. 删掉所有环境铺垫与心理描写，只保留推动冲突的动作和台词。
4. 提高冲突密度，相邻两句之间至少有一次信息推进。
5. 结尾留悬念，明确引导观众看下一集。
6. 文字必须能直接转成分镜与配音：每个动作写明人物、表情、场景，禁止抽象描写。
7. 规避真实作品的人名、宗派名、招式名与标志性桥段。
8. 不出现低俗、暴力血腥、性暗示内容；涉及暴力或卑劣情节时用正向价值收束。
9. 严格遵守各短视频平台的内容规范，不输出任何违规表述。

【输出格式】
分两段输出：
第一段「文案正文」——可直接配音的台词与旁白，按顺序排列。
第二段「适配画面」——逐句对应的镜头描述，含人物、表情、动作、场景。

【原著片段】
{{粘贴原文}}

【目标集数与单集时长】
{{如：第 3 集，单集 60 秒}}
```

> 几乎每条改文指令都会附一句「严格遵守所有短视频平台内容规范」。这不是套话——平台审核是这类内容最大的不确定性，建议直接把红线写进提示词作为硬约束，而不是放在外面靠自觉。

### 原创剧本

结构化写法比自由发挥稳定得多，可复用的框架是把**角色、规格、节奏、内容要求、输出格式**五块固定下来：

```text
你是擅长竖屏漫画式短剧的编剧。请按以下设定创作原创剧本。

【人物】
- 主角：{{姓名}}，身份{{...}}，性格{{...}}，口头禅{{...}}
- 配角：{{姓名 + 与主角的关系 + 性格}}
- 反派：{{姓名 + 动机}}

【规格】
- 集数：{{10}} 集
- 单集时长：{{1～2}} 分钟
- 单集字数：约 {{700}} 字

【节奏结构】按百分比分配，不要平均用力
- 0–10%　强钩子开场，不做背景交代
- 10–40%　小事件推到小高潮
- 40–60%　重大反转，且反转必须由前文线索支撑
- 60–85%　最强冲突
- 85–100% 快速收束并留下集钩子

【内容要求】
1. 开篇即冲突，每集至少一次反转。
2. 台词口语化、符合人设、精简不啰嗦，每句都有信息点。
3. 避免降智桥段；暴力或卑劣情节需注入正向处理。
4. 不涉及军队、警察、宗教等敏感题材。
5. 国徽国旗谨慎使用；脏话需消音且不宜过多。
6. 不使用与知名在世作品重合的人名、宗派名、招式名。

【输出格式】
分场输出，每场包含：
场号 ｜ 场景（名称+时段）｜ 时间 ｜ 出场人物 ｜ 本场唯一信息点 ｜ 正文（动作与台词分行）

【题材】
{{一句话题材}}
```

按百分比划分节奏，是被大量实践独立采用的做法，可信度较高。真正决定观感的是三个变量：**信息密度、情绪起伏、快慢交替**。只给字数要求而不给节奏划分，模型很容易写出一篇平铺直叙的流水账。

### 分镜输出格式

这是最值得直接抄的一条。核心是**输出字段固定、结构不许自由发挥**，这样结果才能直接落成分镜表：

```text
你是分镜师。把下面的剧本转成可直接用于 AI 生成分镜表的内容。

【输出格式】严格按以下字段逐镜输出，不增删字段、不改变顺序：
【镜号】+【画面描述】+【台词/旁白】+【音效/背景音乐】+【单镜时长】

【硬性要求】
1. 单集总时长约 {{30}} 秒，开篇前 {{3}} 秒必须设置强看点。
2. 画面描述必须具体具象：人物姓名、站位、表情、动作、场景环境、光线、景别，
   写成可以直接丢给生图模型的句子，禁止「气氛紧张」这类抽象描写。
3. 台词口语化、符合人设、精简不啰嗦，每句都有信息点。
4. 画面中不要出现需要生成的中文文字（招牌、屏幕、书本）；需要文字时留出空位，
   在音效字段后用「后期加字：{{内容}}」标注。
5. 结尾设置悬念，引导观众看下一集。
6. 单镜时长控制在 {{1～5}} 秒；同一场景的连续镜头时长要有明显节奏差，不要等长。

【镜头语言】
- 相邻镜头避免同景别重复
- 每 {{3～5}} 个镜头至少有一次景别变化
- 人物视线方向在相邻镜头之间保持一致，避免跳轴

【剧本】
{{粘贴剧本}}
```

> 这个格式能直接落成表格，对应<a href="/zh/ecosystem/ai-comic-workflow#环节四分镜与画面">制作流程</a>里的分镜表字段。建议固化成自己的模板，每集必填。

### 素材提取

把剧本转成后续素材时，要保证不丢内容。四类提取**必须拆开写指令**，一次混做模型会串。

```text
你是素材提取员。从下面的剧本中提取全部台词。

【要求】
1. 完整保留原文，不遗漏、不删改、不润色。
2. 以 {{35～50}} 字（含标点）为单句提取上限，超长句按语义拆分。
3. 拆分后的多句对话必须同属一个角色，不得跨角色合并。
4. 不输出旁白和画面描述。
5. 输出格式：场号 ｜ 角色名 ｜ 台词
```

```text
你是素材提取员。从下面的剧本中提取全部旁白与文案。

【要求】
1. 只提取旁白，人物台词单独保留，不要混在一起。
2. 旁白改为口语句式，去掉书面语连接词，不改变信息。
3. 每条旁白补一句建议配图方向（一句话）。
4. 输出格式：场号 ｜ 旁白原文 ｜ 建议配图方向
```

```text
你是设定提取员。从下面的剧本中分别提取三类信息，不要混做。

1. 角色：姓名、年龄段、体型、发型、服装配色、标志性道具、性格
2. 场景：名称、时段（室内/室外）、主要陈设、光线氛围
3. 道具：名称、材质、尺寸、在哪一场出现

【要求】
- 每类单独成表
- 字段缺失写「未提及」，禁止自行编造
- 不输出剧本原文

【剧本】
{{粘贴剧本}}
```

```text
参考下面的成片结构，输出一份可复用的分镜结构分析：

1. 按时间轴列出每个镜头：景别、时长、在叙事中的作用
2. 标注三个关键钩子分别出现在第几秒，用了什么手法
3. 标注节奏变化点：加速、停顿、留白
4. 最后给出不涉及具体内容、可以套用的结构模板

【要求】
- 不要复述剧情
- 不要输出原片台词
- 只分析结构

【参考片段描述】
{{粘贴时间轴或分镜描述}}
```

> 视频反推只用于学习节奏和结构，不要把原片台词或具体情节拿进自己的成片。

## 角色与画风

### 角色卡

角色一致性的解法是先出角色卡，再固定视角出图。角色卡最怕写成「女主，20 岁」这种没法落地的描述——**字段必须具体到能直接喂给生图模型**：

```text
你是角色设定师。根据下面的剧本，为每个出场角色建立可用于 AI 生图的角色卡。

【字段】
姓名 ｜ 年龄段 ｜ 性别表达 ｜ 体型 ｜ 发型（刘海、长度、发色）
｜ 服装（上衣、裤子、鞋、配色 HEX）｜ 标志性配饰 ｜ 表情基线
｜ 性格 ｜ 常用动作与口头禅 ｜ 声线特征

【要求】
1. 只使用剧本中能推出的信息，推不出的写「待定」，禁止编造与原作冲突的设定。
2. 服装与配色必须写具体款式和颜色，不能写「日常服装」。
3. 只写跨集不变的字段，把随剧情变化的临时状态单独列在备注里。
4. 为每个角色补一句「一句话视觉锚点」，例如「永远戴红框眼镜、左手有疤」，
   用于后续所有画面保持一致。
5. 为每个角色补一句「一句话声音锚点」，例如「偏沙、语速慢、句尾下沉」。

【剧本】
{{粘贴剧本}}
```

### 三视图

```text
生成角色三视图设定图。

【内容】
1. 正面全身站姿、左侧面全身站姿、背面全身站姿，并附一张正面头像。
2. 背景为纯白，无场景、无道具、无文字、无边框。
3. 四图横向并排，人物高度一致、比例一致、不要表格线。
4. 严格依据角色卡的外形描述，不增删服装配饰，不改变配色。
5. 线条与光影保持中性，便于后续作为一致性参考。

【画幅】
16:9 横图

【角色卡】
{{粘贴角色卡}}
```

另有「人物微表情控制」和「演员定妆照提取」等进阶指令，用于在已有角色卡基础上收紧跨集漂移。

### 画风分类

以下七分类是被大量实践独立采用的同一套切分，可以直接当作选画风的索引：

| 分类             | 覆盖范围              |
| ---------------- | --------------------- |
| 写实与影视类     | 真人质感、影视级光影  |
| 3D 与渲染类      | 3D 渲染、游戏引擎风格 |
| 动漫与二次元类   | 2D 日系、少女漫画     |
| 国风与古风类     | 国漫古风、水墨        |
| 韩漫与韩风漫画类 | 韩式漫画线条          |
| 暗黑与个性漫画类 | 强烈对比、个性化      |
| 唯美梦幻与童话类 | 柔和低饱和、童话感    |

另有一套按角色与场景细分的画风词库分类，在上述六大类之外补充了质感光影、潮流特殊风格等维度。**词库规模不必追大**：选定的每一组词都要在整季里保持不变，一致性比丰富度重要。

选定画风时用下面这套提示词，选完之后把主画风那段话存下来，之后所有画面提示词都复用它：

```text
根据下面的角色与题材，选定一个主画风，并给出可直接使用的完整描述。

【候选画风】
{{从上面七类里填入最匹配的 2 个}}

【输出】
1. 主画风：{{名称}}
2. 画风提示词：一段完整描述，必须覆盖线条、色彩、光影、质感、镜头感五项，
   写成可以直接粘进生图提示词的一段话
3. 配色方案：主色 / 辅色 / 点缀色各 1 个，给出 HEX
4. 冲突词：该画风下禁止同时出现的风格词，列出 3～5 个

【角色卡】
{{粘贴角色卡}}

【题材】
{{一句话题材}}
```

### 运镜提示词

运镜要按运动类型固定成模板，配合景别切换复用，而不是每次临时描述。临时描述的运镜词前后不一致，成片会明显晃。

| 运动类型 | 可直接复用的运镜词                                     |
| -------- | ------------------------------------------------------ |
| 推       | 镜头缓慢向前推进，从{{中景}}到{{近景}}，速度均匀无抖动 |
| 拉       | 镜头缓慢向后拉远，从{{特写}}到{{全景}}，速度均匀无抖动 |
| 摇       | 镜头位置固定，水平摇动从{{A}}转向{{B}}，匀速无停顿     |
| 移       | 镜头水平平移跟随{{人物}}，人物始终保持在画面同一位置   |
| 升降     | 镜头垂直{{上升/下降}}，俯仰角保持不变，速度均匀        |
| 环绕     | 镜头围绕{{人物}}匀速环绕 90 度，背景视差明显           |

用法：一张分镜表的运镜字段只允许填表里这六类 + 景别（远景、全景、中景、近景、特写）。想加新运镜，先加进表里再用于全片，不要单集临时造词。

### 纯场景提示词

生成纯背景场景时，多份实践给出了强约束写法。四条规则缺一条就可能串进人物：

1. 画面中严禁出现任何人影、人体局部、人物剪影或人脸。
2. 场景描述中严禁出现任何角色人名。
3. 所有提示词必须以「不能出现其他人，无人纯场景」开头。
4. 严禁输出括号内的说明文字，直接输出最终提示词内容。

```text
生成纯场景背景图，硬性要求：

1. 画面中严禁出现任何人影、人体局部、人物剪影或人脸。
2. 场景描述中严禁出现任何角色人名。
3. 严禁输出括号内的说明文字，直接输出最终提示词内容。

【本次场景】{{不少于四个字，如「雨夜便利店门口」}}
【时段与光线】{{如：夜晚，霓虹招牌反射的冷光为主光源}}
【关键陈设】{{列出 3～5 件必须出现的物体}}
【画风】{{粘贴整季统一画风提示词}}
【配色】{{粘贴主色/辅色/点缀色}}
【画幅】9:16 竖屏
```

> 这几条是实战踩坑总结。人物串进背景镜头会导致整集画面不一致，后期修图成本远高于一开始就约束好。

## 画面与镜头

### 单片段生成

通行做法是**每个独立视频片段严格锁定 15 秒**，便于后续拼接和对齐。生成时必须把上一镜的信息一起带进去，否则人物站位和光线会跳。

```text
按分镜表生成本镜画面。

【镜号】{{03}}
【时长】严格 {{15}} 秒
【景别 / 机位 / 运镜】{{中景 / 平视 / 缓慢推进}}
【人物站位】{{主角居画面左前 1/3，背景右侧为窗}}
【动作与表情】{{具象描述}}
【台词或内心独白】{{不超过台词字数上限，字数上限见变量表}}
【必须保持】
- 角色卡中的脸型、发型、服装、体型、配饰完全一致
- 整季统一画风提示词与配色方案不变
- 与上一镜一致的视线方向、光线方向和人物站位
【禁止】
- 画面内出现任何中文字符
- 出现与角色卡不符的服装、配饰或人物

【画幅】9:16
【上一镜要点】{{上一镜的站位、视线、光线}}
```

```text
本镜应保留的人物：{{角色名}}
```


### 一致性审片

批量出图后用这一段做机器初审，把人工抽查的范围缩小到机器点名的镜头：

```text
你是分镜审片员。对照角色卡与分镜表，逐镜检查并输出问题清单。

【角色卡】
{{粘贴角色卡}}

【分镜表】
{{粘贴分镜表}}

【画面描述】
{{逐镜贴图或描述}}

【检查项】每镜输出：
1. 外形一致性：脸型、发型、服装、体型与角色卡的差异点
2. 手部异常
3. 画面内是否有文字
4. 站位与视线方向是否与上一镜冲突
5. 景别与光线是否与分镜标注一致
6. 时长是否满足分镜要求

【输出要求】
- 只列问题，按严重程度排序，不要输出表扬性描述
- 每条问题标注镜号、问题类型、一句话修改建议
```

## 声音规范

### 角色音色定义

音色是投入最多的素材之一，但**关键不是有多少条，而是每个固定角色锁死一条**。定义时用下面这套，一次性把音色、语速、停顿都写死：

```text
为角色卡中的每个角色定义固定音色。

【输出字段】
性别倾向 ｜ 年龄感 ｜ 音色质地 ｜ 语速（字/分钟）｜ 语调起伏
｜ 停顿习惯 ｜ 声音锚点（一句话）

【要求】
1. 同一角色的旁白与对白使用同一音色。
2. 每个角色给 2 个备选，标注主选与备用，备用只在主选失效时启用。
3. 输出可直接使用的参数描述，不要只写形容词。
4. 与角色卡中的「声音锚点」保持一致。
5. 不要为同一角色推荐同一音色的多个说法。

【角色卡】
{{粘贴角色卡}}
```

### 配音生成

```text
按分镜表生成配音。

【音色】
{{角色名}} → {{音色描述}}，语速 {{X}} 字/分钟

【情绪曲线】{{本集情绪走向，如：压抑 3 分 → 爆发 8 分 → 收束 4 分}}

【要求】
1. 台词逐句生成，不合并不删改。
2. 关键台词前后留 {{0.3～0.5}} 秒停顿。
3. 情绪标注写在括号内作为朗读提示，不要读出括号内容。
4. 每句输出格式：镜号 ｜ 台词 ｜ 情绪标注
5. 同一角色的所有句子必须使用同一音色，不得漂移。
6. 旁白与对白分开输出，旁白单独一组。

【分镜表】
{{粘贴分镜表}}
```

> 音色一致性是系列内容最容易露馅的地方。每集结束后抽听三个关键句，与第一集对比，音色偏移就要重新生成，不要等到观众发现。

### 混音检查

| 层           | 作用             | 音量关系                 |
| ------------ | ---------------- | ------------------------ |
| 人声         | 承载信息         | 始终最高                 |
| 背景音乐     | 情绪推进         | 低于人声，关键台词处再降 |
| 环境音与音效 | 空间感与动作反馈 | 短暂抬高，不能盖过人声   |

```text
你是混音审听员。对照以下声音分层配置检查问题并给出调整建议。

【分层】人声 ｜ 背景音乐 ｜ 环境音 ｜ 音效
【本集情绪曲线】{{...}}

【检查项】
1. 是否存在人声被音乐或音效盖住的时段，给出秒数
2. 关键台词处的音乐是否需要再降
3. 音效是否过响或过密
4. 音色是否在集内发生跳变，标出跳变镜号
5. 语速是否与画面节奏匹配

【输出】
只输出问题与调整建议，按严重程度排序。
```

戴耳机听一遍，人声被盖住就是不合格；外放听一遍，音效刺耳也要调。

## 审核与合规

详细红线清单见<a href="/zh/ecosystem/ai-comic-compliance">合规与授权</a>。这里给的是两段可执行的提示词。

### 送审前自检

```text
你是发布前合规审片员。对照下面的清单逐项检查，输出不通过项。

【红线清单】
1. 不涉及军队、警察、宗教等敏感题材
2. 不出现具体省份地名和真实历史人物
3. 国徽、国旗、人民币等元素不做变形或戏谑化处理
4. 两性内容以暗示和氛围为主，不做直白描写
5. 暴力或低俗情节已注入正向引导
6. 脏话已消音且数量克制
7. 不触碰他人版权与真人真事，不生成可识别特定在世人物的写实面部
8. 素材、音乐、字体、肖像授权已确认且覆盖商用
9. AI 生成标识已按平台要求保留
10. 无虚假剧情、夸张收益、强制下载等诱导内容

【本片信息】
分镜表：{{...}}
台词：{{...}}
素材来源与授权：{{...}}

【输出】
逐项给出 通过 / 不通过 / 存疑；不通过项写明具体镜号与修改建议；
存疑项写明需要人工确认什么。
```

### 改写为合规画面

```text
下面的画面描述可能触碰平台审核红线，请改写为风险更低的版本。

【原描述】
{{粘贴画面描述或分镜行}}

【改写要求】
1. 不出现可识别特定在世人物的写实面部，改为侧脸、背影、剪影或非写实风格
2. 不出现血液、伤口特写与肢体残缺
3. 两性相关内容改为氛围与暗示，不做直接描写
4. 保持原镜头的景别、机位、运镜、时长与叙事功能不变
5. 保持角色卡外形与整季画风一致

【输出】原描述 ｜ 改写后描述 ｜ 修改理由
```

> 各平台对写实人脸的审核限制差异大且变化快，**必须以平台最新规则为准**，不要照搬任何固定做法，包括这段提示词。

## 提示词变量表

统一用 `{{ }}` 标注需要替换的变量，便于固化成自己的模板，也避免每集重新通读提示词。

| 变量                     | 填什么                   | 备注                       |
| ------------------------ | ------------------------ | -------------------------- |
| `{{粘贴剧本}}`           | 分场剧本正文             | 改文与分镜提示词共用       |
| `{{角色卡}}`             | 角色卡全文               | 生图、审片、混音都依赖它   |
| `{{整季统一画风提示词}}` | 选定的画风描述           | 一季只定一次，之后复用     |
| `{{配色方案}}`           | 主色/辅色/点缀色 HEX     | 同上                       |
| `{{分镜表}}`             | 五字段分镜表             | 配音生成直接吃这张表       |
| `{{上一镜要点}}`         | 站位、视线、光线         | 生图时防跳轴必填           |
| `{{X}}` / `{{N}}`        | 时长、字数、镜数等参数位 | **这里才是需要实测的部分** |
